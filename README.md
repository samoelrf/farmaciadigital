
# Farmácia Digital
Sistema de mapeamento de farmácias e UBSs com disponibilidade de medicamentos em tempo real.

## 🚀 Funcionalidades
- Localização de farmácias e UBSs
- Consulta de estoque de medicamentos essenciais
- Agendamento de retirada
- Notificações e QR Code para atendimento

## 🧠 Tecnologias
Frontend: JavaScript (React.js / React Native)  
Backend: Python (Django / Flask)  
Banco de dados: SQL (PostgreSQL / MySQL)  
Integrações: APIs do SUS (RNDS, BNAFAR)

## 👥 Público-alvo
Cidadãos de baixa e média renda que dependem do SUS e da Farmácia Popular.
